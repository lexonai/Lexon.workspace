# Models (optional)
- humans/human.glb — one rigged character (clips named Idle, Walk, Sit, Typing, Talk; names configurable in config/assets.config.ts). Mixamo / Ready Player Me / Quaternius exports work. Without Sit/Typing clips the Mixamo-style leg bones are bent automatically (verify axes on your rig).
- furniture/desk.glb — desk top + legs, origin at desk centre, ~1.5 x 0.8 m, top at y=0.75.
Missing files fall back to the built-in procedural models. Check each asset's license before shipping.
