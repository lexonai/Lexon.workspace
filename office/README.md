# LEXON OFFICE: runs inside Lexon Workspace
Office is a Node server (web app + API + SQLite) that you host once. **It has no login, password or user list of its own.** People open it from Lexon Workspace (Office page); Workspace signs them in with single sign-on and their Workspace role. AI keys are managed ONLY in Workspace > Integrations > Lexon Office; Office pulls them automatically.

| Step | What |
|---|---|
| 1 | `npm install && npm run build:web` (static app in `web/`, already prebuilt in this package) |
| 2 | copy `.env.example` to your host's env and fill 4 values (`OFFICE_SSO_SECRET`, `OFFICE_GATEWAY_SECRET`, `WORKSPACE_FUNCTIONS_URL`, `OFFICE_FRAME_ANCESTORS`) |
| 3 | `npm run server` (or `docker compose up`), HTTPS in production |
| 4 | Workspace > Integrations > Lexon Office > Link Office: enter the server URL and the same SSO secret |
The server refuses to start without `OFFICE_SSO_SECRET`. The Windows .exe is the Lexon Workspace desktop app (Office is inside it).
Dev: `npm install && npm run dev`.

## Backend
SQLite (`data/office.db`, via better-sqlite3; falls back to a JSON file if it cannot be installed). Roles (owner / admin / viewer) come from the Workspace role via SSO. Background worker runs tasks + schedule when no app is open.
Env: `OFFICE_SSO_SECRET`, `OFFICE_GATEWAY_SECRET`, `WORKSPACE_FUNCTIONS_URL`, `PORT`, `OFFICE_BASE_PATH` (when web build uses a base path), `OFFICE_FRAME_ANCESTORS`.

## AI
AI Models / API Keys → add a provider key (Groq / Gemini / OpenRouter have free tiers). Thumbnails work keyless (Pollinations). Research uses Wikipedia unless you add Tavily/Brave/YouTube keys in Settings.

## v5 — AI office
- 7 rooms (Development, YouTube, Content, Conference, Meeting, Main Floor, Break) with thin walls, doorways and pass-through openings; 35 workers + 1 manager (blue shirt, Conference Room). Everyone walks through doors/corridors.
- **AI is server-side only.** Keys are added in Lexon Workspace (Gemini / Claude / OpenAI / compatible) and pulled by Office. Keys are AES-256-GCM encrypted in the server DB, never sent back to the browser. Workers share the pool; the least-busy healthy key is used and failed over on 429/5xx. A Gemini key only serves Gemini models (several models per key via fast/deep names).
- No pre-written replies: chat, voice calls, manager decisions ([[TASK]]/[[CALL]] actions), meeting discussion and banter bubbles are generated by the configured models. Without a key workers say nothing and the UI tells you to add one.
- Modes: Live, Auto Tour, Follow, Free, **Free Walk** (WASD/joystick, drag to look, collisions). Walk into the Conference/Meeting room and the team sits (then stands) around you; talk to the meeting from the chat bar.
- Tasks → Actions: call the task's people to Meeting/Conference/Development/YouTube/Content room, or give a custom command.

## v6 — self-contained desktop app, real voices, 7 cameras
- **Windows exe is self-contained**: it starts its own server (SQLite DB, AI key vault, task worker, mobile admin) and connects automatically — no `npm run server`. Data lives in `%APPDATA%/LEXON OFFICE/data`. Settings → *Desktop app* shows the mobile-admin URL + password (phone on the same Wi-Fi). Background tasks run while the app is open.
- **Voice**: with a Gemini or OpenAI key (voice models are pre-filled) workers speak with gender-matched server voices (real audio → real waveform) and your speech is recognized by the server (works inside the desktop app; no Google speech service needed). Without such a key it falls back to browser voices / browser recognition.
- **Cameras**: 7 (CAM 01 overview spans two grid cells + one per room incl. Break Area).
- **Graphics**: Settings → Graphics (Auto adapts resolution/shadows/detail to your PC; or High/Medium/Low).
- **Workspace**: new commands/events (mode, room call, calls, AI status) + SSO (`POST /api/sso`) — see `integration/README.md`.

## v7 — performance, CCTV, characters, UI
- **Profiler**: Ctrl+Shift+P (or Settings → Graphics) shows FPS, avg/p95/max frame time, jank frames, draw calls, triangles, geometries/textures. Use it on your PC to confirm smoothness.
- **CCTV**: all 7 feeds are rendered every frame into one GPU atlas and copied tile-by-tile (no readPixels, no frame skipping). Nothing is rendered on non-3D pages.
- **Characters**: 4 base humans (m1, m2, f1, f2) + unique manager, instanced (one draw call per body part for everyone), per-person variation; detail parts (hands, glasses, hair, cup, phone…) only for nearby people (LOD). Drop photoreal GLBs at `public/models/humans/{m1,m2,f1,f2,mgr}.glb` and the 6 nearest people use them (Draco/Meshopt/KTX2 decoders are bundled locally).
- **Compress assets**: `npm run optimize:models` (Meshopt or `--draco`, WebP or `--ktx2` textures, resize).
- **Team**: 28 members = 26 workers (from 4 base characters) + 1 manager + hidden Admin/Owner avatar (premium suit look, appears only in Free Walk).
